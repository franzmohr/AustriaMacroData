# Working with AustriaMacroData as an agent

This repository holds FRED-QD/FRED-MD-style macroeconomic panels for
Austria, with Germany and the United States for comparison. Each country
has one wide CSV per frequency, one column per concept, and every country's
file has the same columns. This file covers **answering questions with the
data**. To change how the data is built, see [README.md](README.md) and
[CONTRIBUTING.md](CONTRIBUTING.md).

## Start here: the semantic layer

| File | What it holds |
|---|---|
| [output/semantic/catalog.json](output/semantic/catalog.json) | Everything in one file: the rules for reading the data, the datasets, the countries, every concept (title, description, synonyms, unit, frequency, codes, caveats, and per-country provider and span), the derived metrics with their formulas, and the transforms |
| [output/semantic/concepts.csv](output/semantic/concepts.csv) | One row per concept, flat |
| [output/semantic/availability.csv](output/semantic/availability.csv) | One row per (country, concept): resolved or not, unit, provider, source key, first and last period |

These files are generated by [R/semantic_layer.R](R/semantic_layer.R) after
every build, so they always describe the panels next to them. Never edit
them by hand.

## The query CLI

[scripts/query.R](scripts/query.R) reads `output/` and fetches nothing. It
writes CSV (or JSON for `describe`) to stdout.

```bash
Rscript scripts/query.R search house prices
```

```bash
Rscript scripts/query.R describe mortgage_rate
```

```bash
Rscript scripts/query.R get --series real_gdp_growth_yoy,inflation_yoy --country AUT,DEU --from 2015-Q1
```

```bash
Rscript scripts/query.R get --series cpi_index --country AUT --freq M --transform yoy --from 2020-M01 --format wide
```

```bash
Rscript scripts/query.R list metrics
```

- `--series` takes **exact** concept labels or derived-metric names. An
  unknown name is an error that suggests the closest matches. It is never
  silently replaced.
- `--transform` can be `level`, `pct_change`, `yoy`, `saar`, `diff`,
  `diff_yoy`, `log`, `log_diff`, `tcode_fred`, `tcode_lt` or `tcode_ht`. It is
  applied before the date filter, so the first period you keep still has its
  lag. In wide output a transformed column is named `<cc>_<series>__<transform>`.
- From R, the same API is `amd_search()`, `amd_describe()` and `amd_get()`
  after sourcing `R/*.R`.

If `Rscript` fails at startup because `renv/activate.R` is missing, run it
as `Rscript --vanilla scripts/query.R ...`.

## Rules that are easy to get wrong

1. **Dates are the first day of the period.** In the quarterly panel,
   `2026-04-01` means 2026-Q2. Quarters are written `YYYY-Qn` and months
   `YYYY-Mnn`.
2. **Quarterly concepts are only in `<cc>_panel.csv`.** National accounts,
   BIS credit, population and hours are never interpolated to months. Monthly
   concepts appear in both panels. In the quarterly panel they are the
   average of the quarter's months, except flows (`aggregation = sum`), which
   are summed.
3. **The current quarter can be partial.** A monthly concept averaged into
   an incomplete quarter uses only the months observed so far. Say so, or
   use complete quarters only.
4. **Check a country's own `unit` before comparing levels.** A concept's
   `unit` in `concepts.csv` is its unit for euro-area members. The unit for
   one country is the `unit` column of `availability.csv` (and of
   `<cc>_metadata.csv`), taken from the source that resolved there. The
   USA's national-accounts levels come from the OECD as USD seasonally
   adjusted annual rates, four times a quarterly level, while EU members'
   come from Eurostat as EUR quarterly levels. FRED series keep their own
   index bases. Levels compare only where the units match. Growth rates
   always compare.
5. **NA means not published or not resolved.** An all-NA column is a
   concept that did not resolve for that country. Many concepts (the EC
   surveys, the HICP components, the ECB mortgage series) exist for EU or
   euro-area members only.
6. **Some columns are identical across countries.** `oil_price` and
   `global_activity` are world series (`scope = world`).
   `euro_area_household_net_worth_growth` is one euro-area figure.
   `short_term_rate` is Euribor for every euro member from 1999 on.
7. **Read the caveats before making a claim.** Each concept's `us_note` and
   `cross_country_note` record how it differs from its FRED-QD namesake and
   where it was spliced. For example, `real_gfcf_total` covers all sectors,
   while FRED-QD's FPIx is private only.
8. **NSA series have seasonality.** These include prices, mortgage flows and
   the primary balance. Compare them year on year.
9. **Data are revised.** To reproduce what was known in a given month, use
   `output/vintages/<cc>_<file>_<YYYY-MM>.<ext>`, not the live file.
10. **Policy dummies** (Austria's KIM-V, Germany's sectoral systemic risk
    buffer) are in `<cc>_dummies_{monthly,quarterly}.csv`. They are listed
    under `policy_events` in the catalog.

## Keeping the layer up to date

- When you add a concept to `concept_dictionary` in
  [R/concept_dictionary.R](R/concept_dictionary.R), add its row to
  `concept_semantics` in [R/semantic_layer.R](R/semantic_layer.R). The row
  needs a title, a one-sentence description, synonyms and a scope.
  `tests/testthat/test-semantic_layer.R` fails until you do.
- To add a derived metric, add a row to `derived_metrics`. The formula is an
  R expression over panel columns, using `ppy` (periods per year),
  `pct_change(x, k)` and `lag_n(x, k)`.
- To regenerate `output/semantic/` without fetching anything, run:

```bash
Rscript scripts/build_semantic_layer.R
```
